Relógio Digital 🕰️
Bem-vindo ao Relógio Digital, um simples projeto HTML, CSS e JavaScript que exibe a hora atual de forma elegante e interativa! ⏰

Como Funciona 🤔
O Relógio Digital utiliza o poder do JavaScript para obter a hora atual do seu sistema e exibi-la de maneira estilizada no seu navegador. As horas, minutos e segundos são apresentados em um layout atraente com a moderna fonte Roboto.
Como Usar 🚀
Baixe ou clone este repositório em sua máquina local.
Abra o arquivo index.html em seu navegador preferido.
Observe o elegante display do relógio digital e veja a mágica acontecer! ✨
Personalização 🎨
Sinta-se à vontade para personalizar o projeto de acordo com suas preferências. Modifique o estilo no arquivo style.css para dar ao relógio um toque pessoal.
Contribuições 💡
Contribuições são sempre bem-vindas! Se você tem ideias para melhorar este projeto ou encontrou algum problema, sinta-se à vontade para abrir uma issue ou enviar um pull request.
